# Rental Property Management System

A web application developed for managing rental rooms, logging tenant data, and automating monthly billing.

## 🛠️ Tech Stack
- **Backend:** Python
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** MySQL

## 🚀 Key Features
- **Tenant Management:** Structured system for logging and checking tenant information.
- **Automated Billing:** Automatically calculates monthly rent, water, and electricity bills to reduce human error.
- **User Interface:** Clean and intuitive frontend design for monitoring room status effortlessly.

🛠️ Tech Stack (เครื่องมือเทคโนโลยีที่เลือกใช้)

• Backend: Python ➔ ระบบหลังบ้าน/การประมวลผลคำนวณเบื้องหลัง พัฒนาด้วยภาษา Python
• Frontend: HTML5, CSS3, JavaScript ➔ ระบบหน้าบ้าน/หน้าจอแสดงผลที่ผู้ใช้มองเห็นและกดใช้งาน
• Database: MySQL ➔ ระบบฐานข้อมูลที่ใช้สำหรับจัดเก็บข้อมูลห้องพักและรายชื่อผู้เช่าอย่างเป็นระบบ

🚀 Key Features (ฟีเจอร์เด่นของระบบ)

• Tenant Management: ระบบจัดการผู้เช่า ที่มีการจัดเก็บและตรวจสอบข้อมูลผู้เช่าอย่างมีโครงสร้างชัดเจน
• Automated Billing: ระบบคำนวณบิลอัตโนมัติ ที่ช่วยคำนวณค่าน้ำ ค่าไฟ และค่าเช่าห้องพักในแต่ละเดือน เพื่อลดความผิดพลาดที่เกิดจากคน (Human Error)
• User Interface: หน้าต่างการใช้งานที่ออกแบบมาให้สะอาดตาและใช้งานง่าย ช่วยให้ผู้ใช้สามารถตรวจสอบสถานะของห้องพักแต่ละห้องได้อย่างสะดวกสบาย
